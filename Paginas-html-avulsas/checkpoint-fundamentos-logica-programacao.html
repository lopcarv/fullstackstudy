Capítulo 01

Introdução e Configuração

O que é Programação e por que Python?

A programação é o ato de fornecer um conjunto de instruções para que um computador execute tarefas específicas. Todos os programas utilizam instruções básicas como blocos de construção, seguindo lógicas como "faça isso; então faça aquilo" ou "se a condição for verdadeira, execute esta ação".

Python é uma linguagem de alto nível, projetada para ser próxima da linguagem humana. Desenvolvida no final da década de 1980 por Guido van Rossum na Holanda e lançada oficialmente em 1991, recebeu seu nome em homenagem ao grupo de comédia Monty Python.

Características Técnicas

  • Interpretada: O interpretador lê o código-fonte linha por linha e o converte em tempo real, facilitando a depuração e o desenvolvimento rápido.
  • Dinamicamente Tipada: Não é necessário declarar o tipo da variável; o sistema infere automaticamente com base no valor atribuído.
  • Multiplataforma: Funciona em Windows, Linux e macOS, sendo gratuita e de código aberto.
  • Versátil: Utilizada em Ciência de Dados, Inteligência Artificial, desenvolvimento web, automação e criação de jogos.

Modos de Uso do Python

  • Shell Interativo: Ideal para testar expressões. Identificado pelo prompt >>>.
  • Modo Script: Código completo salvo com extensão .py e executado como programa.

Configuração do Ambiente

Windows

  • Baixe em python.org/downloads
  • Importante: Marque "Add Python to PATH" durante a instalação.

Linux (Ubuntu)

macOS

Editores Recomendados

  • VS Code: O mais popular, gratuito e com extensão oficial para Python.
  • IDLE: Editor padrão que acompanha o Python. Simples e bom para iniciantes.
  • Geany: Leve e eficiente para Windows e Linux.
  • Sublime Text: Rápido e elegante, muito comum no macOS.
  • Online: Programiz, Repl.it ou Google Colab.

Primeiro Programa: "Olá Mundo!"

print("Olá Mundo!")

A função print() exibe informações na tela. O texto dentro das aspas é chamado de String.

Boas Práticas — PEP 8

  • Indentação: 4 espaços por nível de recuo.
  • Comentários: Use # para notas explicativas.
  • Nomenclatura: Use snake_case (ex: nome_do_usuario).
  • Tamanho de linha: Máximo de 79 caracteres.

Erros Comuns

  • SyntaxError: Parêntese, aspas ou dois-pontos ausentes.
  • NameError: Variável não definida ou nome digitado errado.
  • IndentationError: Código não recuado corretamente após um bloco.

Capítulo 02

Variáveis e Tipos de Dados em Python

O que são Variáveis?

Uma variável é um espaço reservado na memória RAM do computador para armazenamento temporário de informações. Funciona como uma caixa rotulada onde guardamos um valor para uso posterior.

Os dados em variáveis são voláteis — existem apenas enquanto o programa está em execução. A sintaxe básica de atribuição é:

mensagem = "Olá mundo!"
idade = 25
preco = 10.50

Regras de Nomenclatura

  • Pode conter letras, números e underscores (_).
  • Deve começar com letra ou underscore — nunca com número.
  • Sem espaços, acentos, hifens ou caracteres especiais (@, $, !).
  • Não usar palavras reservadas como print, input, if, for, class.
  • Python diferencia maiúsculas de minúsculas: spam, SPAM e Spam são três variáveis distintas.
Convenção A PEP 8 recomenda snake_case para variáveis: nome_do_usuario é preferível a nomeDoUsuario.

Capítulo 03

Comandos de Entrada, Saída e Operadores

Saída de Dados com print()

A função print() exibe informações no console. Aceita textos estáticos e variáveis.

Formas de Formatação

# Concatenação
print("Nome: " + nome)

# Método .format()
print("O nome é {} e ele tem {} anos.".format(nome, idade))

# f-strings (recomendado — Python 3.6+)
print(f"Olá, {nome}! Você tem {idade} anos.")

# Formatar casas decimais
print(f"Preço: R$ {valor:.2f}")

Caracteres de Escape

  • \n — Nova linha
  • \t — Tabulação horizontal
  • end='' — Mantém na mesma linha

Entrada de Dados com input()

Regra de Ouro O input() SEMPRE retorna uma string, mesmo que o usuário digite um número. Converta com int() ou float() para usar em cálculos.
nome = input("Digite seu nome: ")
idade = int(input("Digite sua idade: "))
altura = float(input("Digite sua altura (m): "))

Operadores de Comparação

Comparam dois valores e retornam True ou False:

  • == — Igual a
  • != — Diferente de
  • > e < — Maior que e Menor que
  • >= e <= — Maior/menor ou igual

Operadores Lógicos

  • and — Verdadeiro somente se ambas as condições forem verdadeiras.
  • or — Verdadeiro se pelo menos uma for verdadeira.
  • not — Inverte o valor lógico.

Operadores de Atribuição Expandidos

x += 1   # equivale a x = x + 1
x -= 5   # equivale a x = x - 5
x *= 2   # equivale a x = x * 2
x /= 3   # equivale a x = x / 3

Exemplo: Calculadora de Média

nome_aluno = input("Nome do aluno: ")
nota1 = float(input("Digite a primeira nota: "))
nota2 = float(input("Digite a segunda nota: "))

media = (nota1 + nota2) / 2
print(f"O aluno {nome_aluno} obteve a média {media:.1f}")

Estruturas de Seleção (Decisão)

Estrutura Simples: if

Executa um bloco de código apenas se a condição for verdadeira.

if condição:
    # bloco executado se True
Regra de Ouro Em Python, a INDENTAÇÃO (4 espaços) define a hierarquia do código. Esquecer de indentar gera IndentationError.

Estrutura Composta: if-else

idade = 15
if idade >= 18:
    print("Pode dirigir")
else:
    print("Não pode dirigir")

Seleção Múltipla: if-elif-else

nota = 7
if nota >= 7:
    print("Aprovado")
elif nota >= 5:
    print("Recuperação")
else:
    print("Reprovado")

Operador Ternário

resultado = "Aprovado" if nota >= 7 else "Reprovado"

match case (Python 3.10+)

Útil para comparar uma variável com várias constantes, mais legível que longas cadeias de elif. Funciona de forma similar ao switch de outras linguagens.

Capítulo 05

Estruturas de Repetição (Laços)

O Conceito de Iteração

A iteração é o processo no qual um conjunto de instruções é repetido em sequência por um número específico de vezes ou até que uma condição seja alcançada. Laços evitam código repetitivo e tornam programas eficientes e escaláveis.

while — Enquanto

Executa um bloco enquanto a condição for verdadeira.

contador = 1
while contador <= 5:
    print(contador)
    contador += 1
Cuidado Se você esquecer de atualizar a variável de controle, o programa entrará em LOOP INFINITO. Para interromper: pressione CTRL+C no terminal.

Valores Truthy e Falsey

# Loop de validação de entrada
nome = ''
while not nome:
    nome = input("Por favor, digite seu nome: ")

for — Para

Ideal para iterar sobre sequências ou quando se sabe o número de repetições.

magicos = ['alice', 'david', 'carolina']
for magico in magicos:
    print(magico.title() + ", isso foi um ótimo truque!")

A função range()

range(5)           # 0, 1, 2, 3, 4
range(1, 6)        # 1, 2, 3, 4, 5
range(0, 10, 2)    # 0, 2, 4, 6, 8 (pares)

Contadores e Acumuladores

# Somatório de Gauss: soma de 1 a 100
total = 0
for num in range(1, 101):
    total += num
print(f"A soma total é: {total}")

break e continue

  • break — Sai imediatamente do laço.
  • continue — Pula para a próxima iteração, ignorando o restante do ciclo atual.

Laços Aninhados

# Tabuada completa
for i in range(1, 11):
    for j in range(1, 11):
        print(f"{i} x {j} = {i*j}")

Capítulo 06

Coleções de Dados (Listas)

O que é uma Lista?

Uma lista é uma coleção de itens mantidos em uma ordem específica. Permite armazenar múltiplos valores em uma única variável, de tipos diferentes.

bicicletas = ['trek', 'cannondale', 'redline', 'specialized']
dados_mistos = ['python', 42, 3.14, True]
lista_vazia = []

Índices e Acesso

Começa em 0 O primeiro item está no índice 0, o segundo no índice 1, e assim por diante. O índice -1 retorna o último elemento.
print(bicicletas[0])   # 'trek'
print(bicicletas[-1])  # 'specialized'
print(bicicletas[1:3]) # ['cannondale', 'redline'] — slicing

Manipulando Elementos

# Adicionar
bicicletas.append('honda')           # ao final
bicicletas.insert(0, 'ducati')       # em qualquer posição

# Remover
del bicicletas[0]                    # por índice, sem retorno
ultima = bicicletas.pop()            # remove e retorna o último
bicicletas.remove('cannondale')      # por valor (primeira ocorrência)

# Alterar
bicicletas[0] = 'nova_marca'

Ordenação e Estatísticas

bicicletas.sort()                  # permanente, crescente
bicicletas.sort(reverse=True)      # permanente, decrescente
print(sorted(bicicletas))          # temporário

numeros = [10, 5, 30, 2]
print(len(numeros))    # 4
print(min(numeros))    # 2
print(max(numeros))    # 30
print(sum(numeros))    # 47

Percorrendo com for

magicos = ['alice', 'david', 'carolina']
for magico in magicos:
    print(f"{magico.title()}, esse foi um ótimo truque!")

List Comprehension

# Forma compacta: lista de quadrados de 1 a 10
quadrados = [valor**2 for valor in range(1, 11)]
print(quadrados)

Referências vs. Cópias

Atenção Ao atribuir uma lista a outra variável, você cria uma REFERÊNCIA, não uma cópia. Alterações em uma afetam a outra.
lista_a = [1, 2, 3]
lista_b = lista_a        # referência!
lista_b.append(4)
print(lista_a)           # [1, 2, 3, 4] — lista_a também mudou!

# Para copiar:
lista_c = lista_a[:]     # slicing cria cópia independente

Capítulo 07

Projeto Final — Calculadora de IMC

Descrição do Algoritmo

O IMC é calculado dividindo o peso (kg) pela altura (m) ao quadrado. Este projeto integra todos os conceitos estudados: entrada de dados, conversão de tipos, cálculo matemático, estruturas de seleção e f-strings.

  1. Entrada: Nome, peso e altura do usuário.
  2. Conversão: Texto recebido transformado em float.
  3. Processamento: imc = peso / (altura ** 2).
  4. Classificação: Comparação com tabela da OMS.
  5. Saída: Valor formatado e categoria de saúde.

Implementação Básica

nome = input("Digite seu nome: ")
peso = float(input("Digite seu peso (kg): "))
altura = float(input("Digite sua altura (m): "))

imc = peso / (altura ** 2)

if imc < 18.5:
    classificacao = "Abaixo do peso"
elif imc < 25:
    classificacao = "Peso normal"
elif imc < 30:
    classificacao = "Sobrepeso"
else:
    classificacao = "Obesidade"

print(f"\n{nome}, seu IMC é: {imc:.2f}")
print(f"Classificação: {classificacao}")

Versão com Tratamento de Erros

try:
    peso = float(input("Peso (kg): "))
    altura = float(input("Altura (m): "))
    imc = peso / (altura ** 2)
    print(f"Seu IMC é: {imc:.2f}")
except ValueError:
    print("Erro: digite apenas números usando ponto como separador decimal.")
except ZeroDivisionError:
    print("Erro: a altura não pode ser zero.")

Versão Completa com Loop e Lista

registros = []

while True:
    try:
        nome = input("\nNome (ou 'sair' para encerrar): ")
        if nome.lower() == 'sair':
            break

        peso = float(input("Peso (kg): "))
        altura = float(input("Altura (m): "))
        imc = peso / (altura ** 2)

        if imc < 18.5:
            classificacao = "Abaixo do peso"
        elif imc < 25:
            classificacao = "Peso normal"
        elif imc < 30:
            classificacao = "Sobrepeso"
        elif imc < 40:
            classificacao = "Obesidade"
        else:
            classificacao = "Obesidade Grave"

        registros.append({'nome': nome, 'imc': imc})
        print(f"{nome} → IMC: {imc:.2f} ({classificacao})")

    except ValueError:
        print("Entrada inválida. Use ponto como separador decimal.")
    except ZeroDivisionError:
        print("Altura não pode ser zero.")

if registros:
    maior = max(registros, key=lambda r: r['imc'])
    print(f"\nMaior IMC da sessão: {maior['nome']} ({maior['imc']:.2f})")
Exercícios de Fixação

  2. Refaça o cálculo substituindo (altura ** 2) por (altura * altura). O resultado é igual? Qual tem maior precedência?
  3. Adicione a categoria "Obesidade Grave" para IMC acima de 40. Onde inserir na cadeia elif?
  4. Crie um script que peça a idade do usuário com try/except para tratar entradas inválidas.
  5. Integre uma lista ao projeto. Após 5 cálculos, exiba o nome da pessoa com maior IMC registrado.
